# 实现与测试记录

日期：2026-09-10。环境：Windows、Python 3.14.6，运行时无第三方依赖。

## 已交付

- 单快照、一人一业务全量合成；八类业务、种子复现、最大余数人数分配。
- P1～P5 MOS 单项及演示聚合；解析带宽 inverse/forward 共用接口。

- CLI、使用文档、示例输出和 GitHub Actions 测试配置。

## 验证结果

`python -m unittest discover -s tests -v`：22 项全部通过。包含文档 3.581503 Mbps / 4.510347 MOS 数值例、五组公式、非法输入、配额失败、固定容量冲突、Non-GBR 优先回收、raw 需求更新价格、采样权重、超时返回、步数控制、混合业务和独立 oracle 对照。

本机集成观测（时间不是跨设备性能承诺）：

| 配置 | 场景规模 | 可行结果 | 终止与耗时 |
| --- | --- | --- | --- |
| default | 5 × 30 用户 | 5/5 | 3 局部收敛、2 循环终止；最大约 1.61 秒 |
| tiny | 2 × 3 用户 | 2/2 | 联合穷举参考完成；最大 6 轮，约 9 ms |
| large | 1 × 1000 用户 | 1/1 | 10 秒时间预算触发，约 10.03 秒，返回可行方案 |
| strict_failure | 1 × 3 用户 | 预期生成失败 | 报告当前搜索未发现 severe 候选，退出码 2 |

默认五场景合计加权 MOS 增益约 242.20；千用户场景约 615.96。指标仅适用于固定合成环境。tiny 的实际输入、预测、参考与指标位于 `examples/tiny/`。

## 明确边界

此次交付请求中的数据模拟、求解和联调核心。设计中的多周期时间序列、观测噪声、模型失配、自动抽样后映射回全量、执行与真实反馈未接入，README 已说明。当前未训练现网模型，不下发网络配置，不宣称全局最优或纳什均衡。所有 demo 结果 executable=false。

时间预算覆盖求解器内部，生成和独立 oracle 另计；初始化必须先获得可验证底线，因此时间上限是软预算。网格搜索失败只代表当前搜索未发现，不是数学不可达证明。
