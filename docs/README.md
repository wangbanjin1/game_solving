## 归档规则

- 当前实现仍直接依赖或汇报需要的文档保留在本目录。
- 名称包含“v1”“待审”的历史设计稿放入 `archive/`。
- 原始 OCR/文字提取材料放入 `archive/`，仅用于需求溯源。
- 归档文件不作为当前实现的最终口径；发生冲突时，以当前配置、代码、测试和本目录文档为准。
